### Префиксное дерево для автозаполнения
![](../6.%20Префиксное%20дерево/img/tie.png)

![](../6.%20Префиксное%20дерево/img/radix_tree.webp)
Для маршрутизации запросов я использую префиксное дерево (Trie). В отличие от HashMap, оно позволяет искать не только точные совпадения, но и пути с параметрами ({id}) или wildcard (*)\
В Spring Web эта оптимизация появилась с версии 5.2.\
В API Gateway (например, Spring Cloud Gateway) Trie используется для маршрутизации по path
