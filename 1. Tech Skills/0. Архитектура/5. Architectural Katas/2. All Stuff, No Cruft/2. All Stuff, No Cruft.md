# All Stuff, No Cruft
## Описание в оригинале
Conference organizer needs a management system for the conferences he runs for both speakers and attendees

- Users: hundreds of speakers, dozens of event staff, thousands of attendees
- Requirements:
  - attendees can access speaking schedule online, including room assignments
  - speakers can manage talks (enter, edit, modify)
  - attendees 'vote up/down' talks
  - organizer can notify attendees of schedule changes up-to-the-minute (if attendees opt in)
  - each conference (being a different subject) can be branded independently
  - speaker slides are accessible online only to attendees
  - evaluation system via web page, email, SMS, or phone
- Additional Context:
  - Conference runs across the US.
  - Very small support staff.
  - 'Bursty' traffic: extremely busy when conference is occurring.
  - Conference organizer wants to easily 'skin' the site for different technology offerings.


## На русском
Организатору конференции необходима система управления для проводимых им мероприятий, предназначенная как для докладчиков, так и для участников.

- **Пользователи:** сотни докладчиков, десятки сотрудников службы поддержки, тысячи участников.
- **Требования:**
    - участники могут просматривать расписание выступлений онлайн, включая распределение по аудиториям;
    - докладчики могут управлять своими выступлениями (добавлять, редактировать, изменять);
    - участники могут голосовать «за» или «против» докладов;
    - организатор может оповещать участников об изменениях в расписании в режиме реального времени (при условии согласия участников на получение уведомлений);
    - каждая конференция (по отдельной тематике) может иметь собственный брендинг (оформление);
    - слайды докладчиков доступны онлайн только для участников;
    - система оценки (обратной связи) через веб-страницу, электронную почту, SMS или телефон.
- **Дополнительный контекст:**
    - Конференция проводится по всей территории США.
    - Штат поддержки очень маленький.
    - Нагрузка носит «всплесковый» характер: пиковая активность во время проведения конференции.
    - Организатор хочет иметь возможность легко менять «скин» (внешнее оформление) сайта для различных технологических направлений.

### Участники
- Докладчики (сотни)
- Сотрудники ТП (десятки)
- Участники (тысячи)
- Организатор

### События
- просмотр расписания онлайн. фильтрация по аудиториям. участники.
- crud своих выступлений. докалдчики
- лайк/дизлайк доклада. участики
- согласие/несогласие на получение нотификаций. участники
- оповещение уастников об изменениях расписания. организатор
- кастомизация UI-темы у конференций.
- доступ к презентации онлайн.
- фидбэк через форму ОС, почту, смс, телефон

### Операции
- CRUD расписания
- CRDU выступлений
- дача оценки выступлений
- дача фидбэка на выступление и конференцию
- нотификаций участников с согласием/несогласием
- кастомизация UI-тем
- доступ к презентации онлайн

### Агрегаты
- Конференция
- Доклад
- Выступление
- Нотификация
- Тема оформления
- Фидбэк

### Компоненты
- `IDP` - аутентификация пользователей, выдача токена авторизации
- `ms-roles` - сервис по управлению ролями пользователей
- `ms-feedback` - сервис по управлению фидбэками
- `ms-email-int` - сервис интеграции с электронной почтой
- `ms-sms-int` - сервис интеграции с SMS-службой
- `ms-voice-int` - парсит голосовй фидбэк и кладет его в кафку
- `ms-notification` - сервис по управлению уведомлениями
- `ms-ui-theme` - сервис управлению кастомными темами. Сохранение картинок в S3, генерация CSS с сохранением в S3 и выдача preauth-link на них для FE
- `ms-report` - сервис по управлению докладами
- `ms-conference` - сервис по управлению расписанием, описанием конференции
- `ms-streaming` - сервис по управлению стримингом доклада, выдает конкретному пользователю персональную ссылку на стрим
