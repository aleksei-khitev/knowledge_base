### Systemd
Набор базовых компонентов Linux-системы. Представляет собой менеджер системы и служб, который выполняется как процесс с PID 1 и запускает остальную часть системы.

Помимо прочего, отвечает за:
- запуск демонов по запросу
- управление службами на основе зависимостей
- обсуживание точек (авто)монтирования
- прочее

`systemctl` - Это главная команда для работы с systemd

### Просмотр каталога
- `ls -a` — выводит и скрытые файлы

### Перенаправление вывода
- символ `>` осуществляет перенаправление вывода в указанный файл **с затиранием**\
  <small>так можно обнулить нужный файл: `$ > ls-output.txt`</small>
- символ `>>` осуществляет перенаправление вывода в указанный файл с добавлением в конец файла
- символ `2>` осуществляет перенаправление вывода ошибок
- `$ ls > ls-output.txt 2>&1` вывод ошибок туда же, куда и обычный
- `ls 2> /dev/null` удаление нежелательного вывода

### Конвейер
- конвейеры строятся при помощи `|`, связывая вывод одной команды с вводом другой
- в конвейере можно использовать такие команды как:
    - `sort` - сортирует принятые строки
    - `uniq` - оставляет только уникальные элементы
    - `wc` - подсчитывает строки, слова, байты
    - `tee` - создает T-образное разветвление в конвеере\
      <small>полезно для сохранения промежуточных результатов</small>

```bash
$ ls /bin /usr/bin | sort | tee sorted.txt | uniq | wc -l
1962
$ tail -5 sorted.txt 
zstdgrep
zstdless
zstdless
zstdmt
zstdmt
$
```

### Регулярное выражение
- это символическая форма записи, используемая для идентификации шаблонов в тексте
- символ `^` и знак `$` интерпретируются, как якоря начала или конца
- используя квадратные скобки можно описать совпадение с одним символом из определенного множества
- если сразу после открывающей квадратной скобки стоит символ `^`, остальные символы множества интерпретируются как недопустимые в данной позиции
- записи в виде диапазонов (`[A-Z]`, `[a-z]`)
- поддерживаются классы символов POSIX
- для объединения с другими элементами регулярного выражения, чередование можно заключать в круглые скобки
- в регулярных выражениях могут использоваться различные квантификаторы (`*`, `?`, `{n}`)

```bash
 $ grep -E '(8|[+]7)[ ]?[\(]?[0-9]{3}[\)]?[ ]?[0-9]{3}[-| ]?[0-9]{2}[-| ]?[0-9]{2}$' contacts 
Алла;+7 901 755 10 33
Алина;8 901 755 10 33
Дмитрий;+7 (901) 755 10 33
Егор;+7 (901) 755-10-33
Артем;+7(901)755-10-33
$
```

### awk
разбивает строки на поля (по умолчанию — по пробелам) и позволяет с ними работать
```shell
# Вывести второй столбец (поле) из вывода
ps aux | awk '{print $2}' # Напечатать PID (второе поле)
```

### cut
вырезает части строк (столбцы). Проще, чем `awk`, если вам нужен только один столбец.
```shell
# Вывести 3-й столбец (по пробелам)
cut -d' ' -f3 file.txt

# Вывести 1-й и 5-й столбцы из CSV
cut -d',' -f1,5 data.csv

# Вывести символы с 5-го по 10-й
cut -c5-10 file.txt

# Вывести первые 10 символов каждой строки
cut -c1-10 file.txt
```

### dmesg
- ядро Linux, как и другие программы может и выводит различные информационные сообщения и сообщения об ошибках.
- все они выводятся в буфер сообщения ядра, так называемый `kernel ring buffer`.
- основная причина существования этого буфера - надо сохранить сообщения, которые возникают во время загрузки системы пока сервис Syslog ещё не запущен и не может их собирать.
- чтобы выводить дату, нужно запустить с ключем `-T`
- чтобы увидеть категорию сообщений, нужно использовать ключ `-x`
- чтобы ограничить уровень, нужно использовать ключ `-l`

```bash
$ dmesg -Tx -l warn
kern  :warn  : [Wed Mar 30 08:47:35 2022] PCI: System does not support PCI
kern  :warn  : [Wed Mar 30 08:47:36 2022] Unstable clock detected, switching default 
```

### Архивация и сжатие
- Архивация и сжатие могут выполняться вместе, но это не обязательно
- `gzip` сжимает файл
- `gunzip` восстановливает сжатый файл\
  <small>аналогично `gzip -d`</small>
- `gunzip -c` показывает содержимое сжатого файла\
  <small>можно соединить с `less` через конвейер или использовать `zless`</small>
- `bzip2` похожа на `gzip`, лучше зжимает, но медленнее
- в комплекте идут так же `bunzip2` (распаковка), `bzcat` (просмотр содержимого)
- `tar` архивирует файлы\
  <small>синтаксис: `tar режим[параметры] путь...`</small>
- `tar` может принимать файлы через конвейер и передавать архив через конвейер
- современный `tar` поддерживают сжатие `gzip` и `bzip2` своими средствами, для этого параметры `z` и `j` соответственно
- `zip` и архивирует и сжимает одновременно
- `zip` может принимать список файлов через стандартный вход\
  <small>используя параметр `-@`</small>
- `unzip` позволяет распаковать сжатый архив или извлечь конкретный файл\
  <small>не работат со стандартным вводом</small>

### Подстановка
- в `$(команда)` вставляется результат выполнения команды\
  <small>`$ ls -l $(which cp)`</small>
- в `$переменная` вставляется значение переменной окружения\
  <small>`$ echo "Текущий пользователь $USER"`</small>
- подстановка не срабатывает в одиночных кавычках
- Можно использовать арифметические подстановки\
  <small>`$ echo $(($((5**2)) * 3))`</small>
- Можно делать подстановку даты\
  <small>`$ cp davmail.log "davmail-$(date +%d.%m.%Y_%H:%M.log)"`</small>

### Переменные среды окружения
- команда `printenv` выводит только переменные окружения\
  <small>Если вывод длинный, можно передать вывод в `less` через конвейер</small>
- в `printenv` можно подать на вход имя переменной окружения
- переменные читаются из разных файлов
    - общестстемных: `/etc/environment`, `/etc/profile`
    - пользовательских: `~/.bash_profile`, `~/.bash_login`, `~/.profile`
- команда `export` служит для установки значения переменной окружения\
  <small>чтобы после перезапуска переменная была доступна, нужно добавить export в нужный скрипт</small>
- Некоторые полезные переменные окружения: `PATH`, `USER`, `HOME`

### Псевдонимы
- чтобы не вводить длинные команды, в Linux можно создавать псевдонимы
- с помощью команды `type` можно понять, есть ли такой псевдоним и что он делает
- для создания псевдонима, используется команда `alias`, а для удаления — `unalias`
- чтобы псевдоним сохранился после перезагрузки, нужно добавить его в скрипт инициализации оболочки
    - `/etc/bash.bashrc` для всей системы
    - `~/.bashrc` для пользователя

```bash
$ type prepared_mc
-bash: type: prepared_mc: not found
$ alias prepared_mc='cd /media/hdd1; sudo chmod -R 777 downloads/; mc'
$ type prepared_mc
prepared_mc is aliased to `cd /media/hdd1; sudo chmod -R 777 downloads/; mc'
```

### Периодические процессы
- в Linux периодическими процессами управляет демон `cron`
- он запускается на этапе начальной загрузки системы и выполняется в фоновом режиме до тех пор, пока система не будет выключена
- основной конфигурационный файл `/etc/crontab`
- рекомендуется его редактировать при помощи команды `crontab -e`
- используя `crontab -l` можно посмотреть список задач
- посмотреть состояние `cron` можно выполнив команду `sudo systemctl status cron`
- каждое из полей, задающих расписание, может содержать
    - звездочку (любая цифра)
    - целое число
    - диапазон, разделенный дефисом
    - числе через запятую
    - используя знак деления, можно указать шаг (`*/5` в первом поле — каждые 5 минут)

### rsync
- позволяет синхронизировать каталоги
- синхронизирует только дельту
- быстрый и экономичный по сравнению с другими средствами копирования
- имеет синтаксис\
  `rsync параметры источник приемник`
- роль приемника и передатчика могут играть:
    - локальный файл или каталог
    - удаленный файл или каталог в формате `user@host:path`
    - удаленный сервер rsync, определяемый идентификатором URI `rsync://user@host:port/path`
- или источник или приемник должен находится локально в системе.
- ключ `-v` выводит отладочную информацию
- ключ `-a` обеспечивает рекурсивный обход и сохранение атрибутов файлов
- чтобы удаленные в источнике файлы удалялись и в приемнике нужно добавить параметр `--delete`

### Бит suid
suid (Set User ID) — это специальный бит прав доступа к файлу. Когда он установлен на исполняемом файле, программа запускается с правами владельца файла, а не с правами пользователя, который ее запустил.\
Пример смены пароля
```shell
$ ls -l /usr/bin/passwd
-rwsr-xr-x 1 root root 68208 May 11 2023 /usr/bin/passwd
```
`rws` вместо `rwx`. Буква s означает, что бит `suid` установлен. Владелец — `root`.\
Механика:
- Пользователь vasya запускает `/usr/bin/passwd`.
- Бит suid говорит ядру: "Запусти этот файл от имени владельца (`root`), а не от имени `vasya`".
- Процесс получает `EUID (Effective User ID) = root (UID 0)`.
- Программа может писать в `/etc/shadow`.
- Как только программа завершается, права сбрасываются обратно.
