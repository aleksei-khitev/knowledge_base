## Алгоритмы
### LRU Cache
При превышении лимита хранилища, удаляется самый старый элемент

### Реализация вручную
```java
public class LRUCache<K, V> {
    private final int capacity;
    private final Map<K, Node<K, V>> cache;
    private final Node<K, V> head; // первый элемент в связанном списке
    private final Node<K, V> tail; // последний элемент в связанном списке

    public V get(K key) {
        Node<K, V> node = cache.get(key);
        if (node == null) {
            return null;
        }
        // Перемещаем в начало (самый свежий)
        moveToHead(node);
        return node.value;
    }

    public void put(K key, V value) {
        Node<K, V> node = cache.get(key);
        if (node != null) {
            // Обновляем значение и перемещаем в начало
            node.value = value;
            moveToHead(node);
        } else {
            // Создаем новый узел
            Node<K, V> newNode = new Node<>(key, value);
            cache.put(key, newNode);
            addToHead(newNode);

            // Если превысили емкость, удаляем самый старый (хвост)
            if (cache.size() > capacity) {
                Node<K, V> tailNode = removeTail();
                cache.remove(tailNode.key);
            }
        }
    }
  ...
}
```

### Сокращенный вариант: LinkedHashMap
```java
public class LRUCache<K, V> extends LinkedHashMap<K, V> {
    private final int capacity;

    public LRUCache(int capacity) {
        // accessOrder = true — сортировка по обращению (LRU)
        super(capacity, 0.75f, true);
        this.capacity = capacity;
    }

    @Override
    protected boolean removeEldestEntry(Map.Entry<K, V> eldest) {
        // Если размер превышает емкость — удаляем самый старый элемент
        return size() > capacity;
    }
}
```

### Caffeine: Production Standard
```java
Cache<String, User> cache = Caffeine.newBuilder()
    .maximumSize(10_000)           // 10 000 записей
    .expireAfterWrite(5, TimeUnit.MINUTES) // Истечение через 5 минут
    .recordStats()                  // Сбор статистики (хиты/промахи)
    .build();

User user = cache.get("user123", key -> userRepository.findById(key));
```
- Async загрузка: Можно загружать данные асинхронно.
- Автоматическая статистика: Хиты, промахи, время загрузки.
- Разные стратегии: LRU, LFU, взвешенное кэширование.
- Работает быстрее LinkedHashMap благодаря оптимизациям (ConcurrentHashMap + буферизация операций).
