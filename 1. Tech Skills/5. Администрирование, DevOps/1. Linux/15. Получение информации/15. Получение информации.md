### Работа со списком открытых ресурсов в системе
#### Кто держит порт?
```shell
$ lsof -i :8080
COMMAND   PID   USER   FD   TYPE   DEVICE SIZE/OFF NODE NAME
java    12345  root   46u  IPv6   12345      0t0  TCP *:8080 (LISTEN)
```
#### Какие файлы открыты процессом?
```shell
lsof -p 12345
```

#### Проверить, открыт ли файл другим процессом
```shell
lsof /var/log/myapp/application.log
```

#### Узнать все открытые соединения с конкретным IP
```shell
lsof -i @192.168.1.100
```

#### Узнать, кто использует сеть (все сокеты)
```shell
lsof -i
```
